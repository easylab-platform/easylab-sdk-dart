# easylab-client-sdk-dart

Typed EasyLab client SDK for Dart/Flutter over Connect (easylab.v1 + agent.v1
via the easylab gateway). Generated by buf from
[easylab-platform/proto](https://github.com/easylab-platform/proto).

```dart
final client = EasyLabClient(baseUrl: 'https://easylab.example.com', token: '...');
final repos = await client.listRepos();
```

Consumed as a git dependency:

```yaml
dependencies:
  easylab_client_sdk:
    git:
      url: https://github.com/easylab-platform/easylab-client-sdk-dart.git
      ref: v0.1.0
```
